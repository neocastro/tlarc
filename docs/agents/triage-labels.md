# Triage Labels

The five canonical triage roles map to GitHub labels using the default names
(the repo has no pre-existing label vocabulary to conflict with):

- `needs-triage` — maintainer needs to evaluate
- `needs-info` — waiting on reporter
- `ready-for-agent` — fully specified, AFK-ready (an agent can pick it up
  with no human context)
- `ready-for-human` — needs human implementation
- `wontfix` — will not be actioned
